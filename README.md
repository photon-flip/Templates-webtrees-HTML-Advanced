# Templates for webtrees HTML Block Advanced

Community-maintained examples for the [webtrees HTML Block Advanced module](https://github.com/photon-flip/webtrees-HTML-block-advanced).

Each directory documents one template. Templates that are bundled with the module are documented here as references. The module currently provides its bundled templates locally and does not download templates from this repository.

## Available templates

- [Compact Sampler](compact-sampler/README.md) – the complete demonstration template bundled with the module.
- [Compact Vanilla](compact-vanilla/README.md) – a small, clean starting point with collapsible sections.
- [Variables reference](variables-reference/README.md) – a German-language HTML block demonstrating webtrees tree variables.

## Using a template

Copy the HTML source into an HTML Block Advanced block and save it. Back up any existing block content first: selecting a starter template replaces the editor contents.

Templates in this repository are documentation and examples. They do not yet appear automatically in the module's template picker. That requires a future, explicit integration with a versioned and cached template catalogue.
