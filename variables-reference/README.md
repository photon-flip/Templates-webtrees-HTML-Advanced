# Variables reference

This German-language HTML block demonstrates a selection of webtrees variables for a personal home page or tree home page. webtrees replaces variables enclosed in `#` characters with current values, lists, tables, or charts.

Copy [`template.html`](template.html) into an HTML Block Advanced block. The variables are evaluated when webtrees renders the block, so the displayed values update automatically.

The template includes charts, top-ten lists, favourites, and an alphabetical table of all available variables. The German webtrees manual provides the authoritative documentation and further details: [Variables](https://wiki.genealogy.net/Webtrees_Handbuch/Anleitung_f%C3%BCr_Administratoren/Stammb%C3%A4ume/Variablen).

This is an example rather than a complete compatibility promise: variables can differ between webtrees versions and configurations.
