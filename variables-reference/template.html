Variables in HTML blocks

The variables listed below can be used in HTML blocks on a personal home page or a tree home page.

These variables are automatically updated database values. Use a variable by enclosing its name in # characters; for example, #totalFamilies# is replaced by the current number of families in the tree. Some variables are replaced by charts, while others provide lists or tables.

Further details are available in the German webtrees manual.
