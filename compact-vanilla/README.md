# Compact Vanilla

The **Compact Vanilla** template is bundled with HTML Block Advanced. It is a plain starting point containing several collapsible sections and placeholder text, ready for replacement with a family history, biography, or other custom content.

Use **Compact Vanilla** from the module's template picker. Every `href` and matching `id` for a collapsible section must be unique, including across multiple blocks on the same page.

Source: [`compact-vanilla.phtml`](https://github.com/photon-flip/webtrees-HTML-block-advanced/blob/main/resources/views/html/compact-vanilla.phtml)
