# Compact Sampler

The **Compact Sampler** is the full demonstration template bundled with HTML Block Advanced. It demonstrates navigation, collapsible sections, Bootstrap cards, lists, image placement, and optional additional sections.

It uses image URLs generated by the module at runtime. For this reason, its source remains part of the module and is not a stand-alone HTML file in this repository. Use **Compact Sampler** from the module's template picker.

When adapting the template, replace the sample image URLs with your own public URLs. A dedicated subdirectory below the webtrees `public/` folder is a suitable location for images used in custom blocks.

Source: [`compact-sampler.phtml`](https://github.com/photon-flip/webtrees-HTML-block-advanced/blob/main/resources/views/html/compact-sampler.phtml)
